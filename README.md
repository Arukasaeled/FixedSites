# FixedSites

把常用网站和正在使用的桌面 Agent 放在同一个 Windows 窗口里。

左边选网站，右边选 Agent，中间可以放两份内容。读文档时把 Agent 放在旁边，查资料时并排打开两个网页，用完再回到单页。

## 下载与启动

在 [v1.0 Release](https://github.com/Arukasaeled/FixedSites/releases/tag/v1.0) 下载 `FixedSites-1.0.0-portable.exe`。当前提供 Windows x64 便携版，下载后直接运行。

升级前，从旧版托盘菜单选择「退出程序」，再打开新版。嵌入的 Agent 会先恢复为独立窗口，Agent 自身的进程和任务可以继续运行。仅关闭主窗口可能只是隐藏到托盘。

程序尚未进行代码签名。请从本仓库的 Release 下载，并按需核对随附的 SHA-256。

## 日常怎么用

- **网站放左边。** 添加常用网址后，从侧栏打开。网站目录支持封面、拖拽浏览、搜索和排序。
- **Agent 放右边。** 先在 Windows 中打开应用，再从右栏选择预设并连接目标窗口。支持 DSH、Antigravity、Claude 和 Codex 预设；具体应用版本的窗口表现可能不同。
- **两份内容一起看。** 顶部选择「左右」或「上下」，再从侧栏给空面板放入内容。支持两个网页，或一个网页与一个 Agent。
- **位置和大小随手调。** 点击「换位」，或将一个面板标题拖到另一个标题上。中间的分隔线可拖动，也可聚焦后用方向键调整。「铺满」展开当前面板，再点「还原」回到双栏。
- **收起面板，保留工作。** 面板右上角的关闭按钮只收起显示。网站和 Agent 的关闭、退出按各自规则处理；不会因为收起面板就结束 Agent 任务。

两侧栏可以分别收起。网站弹出的独立窗口带有前进、后退、刷新、地址查看和复制功能，也能在系统浏览器中打开当前地址。主窗口最小化时，独立网页窗口不会跟着最小化。

网页使用自己的登录流程。已保留的网页实例切换时不会重新加载；长时间未使用、没有受保护活动的页面可能被回收。

## 撤销与快照

**撤销只管上一步。** 它覆盖本次运行中的网站添加、修改、删除、排序、封面修改，以及布局调整和面板收起。退出程序后不保留撤销记录，也不接管网页或 Agent 内部的文字撤销。

**快照需要手动保存。** 点击「保存快照」，记录当前页面地址、顶层滚动位置、面板布局、侧栏状态和主窗口位置。只保留一份快照，再次保存会询问是否替换；重新启动后仍可恢复。

快照不保存网页表单、进程内存或 Agent 对话。网站的自定义滚动区域、异步加载内容可能无法恢复到原位置。Agent 需要仍然可连接；快照引用的网站若已从清单删除，需要先撤销删除或重新保存快照。

## Agent 接入说明

FixedSites 通过 Windows 原生窗口嵌入已有桌面应用，不负责向 Agent 发送指令，也不代替这些应用管理对话。

公开版不预置个人安装路径、窗口句柄或进程标识。默认先手动打开 Agent，再选择窗口。如果希望使用「启动并连接」，可在退出 FixedSites 后，于本机 `agents.json` 中为对应条目设置 `launchPath`；保留条目的其他字段。只有配置了启动路径才显示该按钮。

窗口接入失败时，可以重新选择或断开还原。退出 FixedSites 前会尝试恢复原窗口，不会主动结束 Agent 进程。当前只同时展示一个嵌入式 Agent。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 切换前九个常用网站 | `Ctrl+1`～`Ctrl+9` |
| 上一个／下一个网站 | `Ctrl+Shift+Tab`／`Ctrl+Tab` |
| 展开／收起网站栏 | `Ctrl+\` |
| 沉浸模式／恢复界面 | `F11`／`Esc` |
| 网页后退／前进 | `Alt+←`／`Alt+→` |
| 刷新网页 | `Ctrl+R` 或 `F5` |

鼠标侧键继续用于网页前进、后退。快捷键的具体行为取决于当前获得焦点的网页或应用。

## 数据放在哪里

用户数据保存在 `%APPDATA%\FixedSitesBrowser`，不在便携 EXE 所在目录。

| 文件或目录 | 内容 |
| --- | --- |
| `sites.json`、`sites.json.bak` | 网站清单和偏好 |
| `manual-snapshot.json` | 手动保存的快照 |
| `agents.json` | 本机 Agent 配置与所选窗口信息 |
| `site-covers` | 自选的网站封面 |
| `Partitions\fixed-sites` | 网页会话数据 |

升级沿用这个目录和 `persist:fixed-sites` 会话。卸载或替换便携程序不需要清空数据。备份网站清单时，先退出程序，再将清单文件复制到自己的备份位置。

项目没有内置云同步。网页仍会连接各自的网站；Agent 状态观察器只在本机查询进程和支持的状态接口，无法判断时显示未知。请勿把用户目录、Cookie、带私人内容的截图或运行日志提交到公开仓库。更多边界见 [SECURITY.md](SECURITY.md)。

## 从源码运行

需要 Windows x64、Node.js 24 或更新版本，以及系统中的 .NET Framework C# 编译器。构建脚本会编译小型原生窗口宿主。

```powershell
npm ci
npm start
```

构建便携版：

```powershell
npm run dist:win
```

产物位于 `dist/release-1.0.0/`。源码和便携版共用单实例锁，已运行旧实例时，新启动会唤醒旧实例。

检查待提交文件与基本语法：

```powershell
npm run check:public
```

本地维护时可执行 `git config core.hooksPath .githooks`，让提交和推送前自动运行同一检查。

需要验证窗口功能时，可运行 `npm run test:canvas`。它会在 `test/runtime-*` 下创建独立数据和临时示例窗口，不使用正式用户配置。这些运行目录不会提交到 Git。
